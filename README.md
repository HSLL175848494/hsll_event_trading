# HSLL 自动下单

支持 Windows 与 Linux 的桌面 hibt 事件合约交易辅助工具（60+胜率），可接收交易信号，并根据方向、置信度、有效期及用户配置自动执行下单，同时支持自定义单笔金额和信号阈值、控制自动下单状态、设置每日订单数、累计金额、止损与止盈等风控限制，以及跟踪待验证订单、保存订单明细和结算结果、查看日度与月度订单统计、胜率和盈亏趋势，并提供运行日志、配置管理及本地数据导入导出功能。自动交易存在风险，请仅操作本人或已获合法授权的账户，并根据自身情况合理设置风控参数。
